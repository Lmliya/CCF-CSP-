🛠️ C++ 语法复健与 CCF CSP 高频 STL 模板速查

CCF CSP 考场支持 C++14/17 标准，且允许携带纸质资料。复健核心不是背冷门语法，而是熟练掌握 万能头文件、快读、6大 STL 容器（vector / string / set / map / queue / priority_queue）与 sort 自定义排序。

1. 考场起手万能模板与输入输出（防 TLE 必写）

对应洛谷 P1001 / P1308 
#include <bits/stdc++.h> // 一行包含所有标准库与STL容器
using namespace std;
typedef long long ll;    // CSP T2-T5 极易爆 int，求和一律用 ll

int main() {
    // 关闭同步流：加速 cin/cout，数据量 10^5 以上必加！
    ios::sync_with_stdio(false);
    cin.tie(nullptr);

    int n;
    if (!(cin >> n)) return 0;
    // 读取含空格的整行字符串（如 T3 文本解析）
    string line;
    getline(cin >> ws, line); // ws 自动吃掉前导换行符
    return 0;
}

2. 动态数组 vector、去重与结构体多关键字排序

对应洛谷 P1059 / P1093 
struct Node {
    int id, score;
};
vector<int> a = {5, 2, 5, 1, 3};
// 1. 升序排序 + 原地去重（CSP 离散化与统计常客）
sort(a.begin(), a.end());
a.erase(unique(a.begin(), a.end()), a.end());

// 2. 二分查找：第一个 >= x 的位置
int idx = lower_bound(a.begin(), a.end(), 3) - a.begin();

// 3. Lambda 自定义排序：分数降序，同分按 id 升序
vector<Node> stu = {{1, 90}, {2, 95}, {3, 90}};
sort(stu.begin(), stu.end(), [](const Node& x, const Node& y) {
    if (x.score != y.score) return x.score > y.score;
    return x.id < y.id;
});
